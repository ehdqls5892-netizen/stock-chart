# COF 종목필터 + 차트 분석 (GitHub 자동화 버전)

평일 16:40(한국시간)마다 GitHub가 KRX 실데이터로 코스피·코스닥 후보 종목을 걸러
`docs/data/`에 저장하고, GitHub Pages 주소로 아이폰에서 바로 봅니다. 서버·PC 필요 없음, 무료.

## 무엇을 계산하나
- **후보군**: 당일 거래대금 상위 120 + 등락률 상위 60 (거래대금 50억 이상), 그중 강한 순 60종목 상세 분석
- **단타**: 거래대금 평소(20일 평균) 대비 3배↑ · 등락률 +3%↑ · 고가권 마감(봉 위쪽 30% 안) · 당일+전일 수급 — 3개 이상 + 거래대금 급증 필수
- **스윙**: 외국인 20일 중 10일↑ 순매수 · 외국인+기관 20일 누적 순매수 · 정배열(5>20>60일선) · 20일선 이격 0~12% · 60일 고가 근접 — 4개 이상 + 정배열 필수
- **X-ray 거래량**: 60일 캔들과 매수/매도 몫 추정 막대 (트레이딩뷰 지표와 같은 식)

조건값은 `screener/cof.py` 맨 위 `DANTA`, `SWING`에서 바꿀 수 있습니다.

## 설정 (한 번만, 약 30분)
1. **KRX 계정 만들기**: data.krx.co.kr 에서 회원가입 (pykrx가 로그인해야 데이터를 줍니다)
2. **GitHub 저장소 만들기**: github.com → New repository → 이름 예: `cof-filter` → **Private** 추천
3. 이 폴더의 파일 전체를 업로드 (Add file → Upload files, `.github` 폴더 포함)
4. **비밀값 등록**: Settings → Secrets and variables → Actions → New repository secret
   - `KRX_ID` = KRX 아이디, `KRX_PW` = KRX 비밀번호
5. **Pages 켜기**: Settings → Pages → Source: Deploy from a branch → Branch `main`, 폴더 `/docs` → Save
   - Private 저장소의 Pages는 유료 플랜이 필요합니다. 무료로 쓰려면 저장소를 Public으로 (비밀번호는 Secrets에 있어 노출되지 않음)
6. **첫 실행**: Actions 탭 → "COF 장마감 스크리닝" → Run workflow
7. 몇 분 뒤 `https://<깃허브아이디>.github.io/cof-filter/` 접속 → 아이폰 Safari 공유 → **홈 화면에 추가**

## 문제가 생기면
- Actions 로그에 "시세가 비어 있습니다" → 휴장일이거나 KRX 로그인 실패(비밀값 확인)
- pykrx 버전이 바뀌어 함수가 깨지면 `requirements.txt`의 버전을 고정한 채로 두고 Claude에게 로그를 보여주세요

## 주의
기계적 필터 결과이고 매수·매도 추천이 아닙니다. 매수/매도 거래량은 봉 모양으로 추정한 값입니다.

## 장중 텔레그램 알림 (Claude 사용량 0)

평일 장중 15분마다 감시 종목 시세를 확인해 텔레그램으로 보냅니다.
- 장 시작 후 첫 실행: 감시 종목 전체 시초 요약
- 이후: 등락률이 3·5·10·15·20%를 새로 넘을 때만 알림 (같은 구간 중복 없음), 거래량 20일 평균 3배↑ 표시
- 감시 대상: 전날 COF 단타·스윙 후보 + `config/watch.json`에 적은 종목
- 시세 출처 Yahoo Finance: 한국 종목은 약 15~20분 늦을 수 있고, GitHub 예약 실행도 몇 분씩 밀릴 수 있습니다.

### 텔레그램 봇 만들기 (5분)
1. 텔레그램 앱에서 **@BotFather** 검색 → `/newbot` → 이름 입력 → **토큰**(예: `123456:ABC...`)을 받습니다.
2. 방금 만든 봇과 대화를 열고 아무 메시지나 보냅니다(예: `hi`).
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id":숫자` 의 숫자를 찾습니다. 이것이 **채팅 ID**입니다.
4. GitHub 저장소 Settings → Secrets and variables → Actions 에 등록:
   - `TG_TOKEN` = 봇 토큰
   - `TG_CHAT` = 채팅 ID
   - `DASH_URL` = 주식비서 데스크 링크 (선택, 알림에 "대시보드 열기" 링크가 붙음)
5. Actions 탭 → "장중 알림 (텔레그램)" → Run workflow → market `kr` → 텔레그램에 테스트 메시지가 오면 완료.

### 감시 종목 바꾸기
폰의 GitHub 앱에서 `config/watch.json`을 열어 연필 아이콘으로 수정 → Commit. 다음 실행부터 반영됩니다.

### 사용량
GitHub Actions 무료 한도: 공개 저장소는 무제한, 비공개는 월 2,000분입니다. 이 알림은 하루 약 60회 × 1분 정도라 비공개면 한도에 가까울 수 있어 공개 저장소를 권합니다 (비밀값은 노출되지 않음).

## 차트 분석 (주식비서 데스크와 연결)

`screener/chart.py`가 매일 장 마감 후 시세를 받아 차트 신호를 계산하고 `docs/data/chart-kr-latest.json`, `chart-us-latest.json`에 저장합니다. Claude 마감 리포트가 이 파일을 읽어 추천·상승여력 후보를 고를 때 함께 쓰고, 대시보드에서 종목을 누르면 캔들 차트가 열립니다.

- 계산하는 신호: 장대양봉·망치형·역망치형·상승장악형·도지 / 유성형·윗꼬리 음봉·장대음봉·하락장악형, 정배열·역배열, 골든·데드크로스(5·20), 20일선 회복·이탈, 지지·저항(여러 번 반응한 가격대), 박스권 돌파·상단 근접, 쌍바닥·쌍봉, 역헤드앤숄더, 저점 높이기·고점 낮추기, 거래량 배수, 급등 후 거래량 감소, 갭하락, 5일 연속 하락, 과열 이격, 가격·매수량 다이버전스
- 같은 캔들도 자리(추세·지지/저항 위치)에 따라 다르게 판정합니다. 예: 망치형은 하락 끝이나 지지선에서만 반등 신호로 셉니다.
- 분류: 돌파·돌파 대기 / 반등 신호 / 추세 관심 / 추격 금지·주의
- 대상 종목: `config/universe_kr.json`(한국 115개), `config/universe_us.json`(미국 77개) + `config/watch.json` + 전날 COF 후보. 파일에 종목을 추가하면 다음 실행부터 포함됩니다.
- 실행 시각: 한국 평일 16:05(KST), 미국 평일 장 마감 후(뉴욕 16:35~17:35). Claude 리포트는 그 뒤(한국 17:10, 뉴욕 18:20)에 실행됩니다.

### 연결 방법
1. 저장소는 **Public**이어야 합니다 (Claude가 결과 파일을 읽을 수 있도록).
2. Actions 탭에서 **한국장 마감 분석 (COF + 차트)** 와 **미국장 마감 차트 분석** 을 각각 Run workflow 로 한 번 실행합니다. KRX 계정이 없으면 COF 단계는 건너뛰고 차트 분석만 실행됩니다(정상).
3. 끝나면 `docs/data/chart-kr-latest.json` 파일이 생깁니다. Claude에게 **GitHub 아이디**를 알려주면 대시보드와 연결해 줍니다.

규칙에 따른 기계적 분류이며 매수·매도 추천이 아닙니다. 차트 신호의 실제 적중률은 대시보드의 "다음 날 결과" 기록으로 확인하세요.
