# 토스 실시간 단타 로봇

토스증권 Open API로 **실시간 체결 시세(초 단위)**를 받아, 정해진 규칙에 맞으면 사고 익절·손절까지 자동으로 하는 프로그램이에요.
내 PC에서 돌아가고 **Claude 사용량은 쓰지 않아요.** 후보 종목을 고를 때 깃허브 차트 분석 결과(stock-chart)도 같이 참고해요.

> ⚠️ 자동매매는 버그·급락·통신 장애로 손해가 날 수 있어요. **처음 2주는 꼭 연습 모드**로 돌려 결과를 확인하세요. 투자 판단과 책임은 본인에게 있어요.

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| 윈도우 PC | 장 시간에 켜져 있어야 해요 (잠자기는 괜찮아요. 예약 시간에 깨워요) |
| 파이썬 3.11 이상 | python.org → Downloads → 설치할 때 **"Add python.exe to PATH" 체크** |
| 토스 Open API 키 | 토스증권 PC 웹(WTS) → 설정 → Open API → Client Id / Client Secret |
| 허용 IP | 같은 화면 **허용 IP 관리**에 이 PC의 인터넷 주소가 있어야 해요 |

**키는 절대 남에게 보여주거나 채팅·캡처로 공유하지 마세요.** 노출됐다면 바로 **재발급**하세요.

---

## 2. 처음 한 번 설정

1. 이 폴더를 원하는 곳에 압축 풀기 (예: `C:\tossbot`)
2. **`0_설치.bat`** 더블클릭 → 설치가 끝나면 메모장이 열려요
3. 메모장에 이렇게 붙여넣고 저장 (따옴표 없이)
   ```
   TOSS_CLIENT_ID=tsck_live_...
   TOSS_CLIENT_SECRET=tssk_live_...
   ```
4. **`1_연결확인.bat`** 더블클릭 → 아래처럼 나오면 성공 (주문은 하지 않아요)
   ```
   1) 토큰 발급 … OK
   2) 계좌 … BROKERAGE ****1234 (seq 1)
   3) 현재가 005930 … 71500
   ✅ 연결 확인 끝
   ```
   - `403` 이 나오면: 허용 IP 에 이 PC 주소가 없어요. 토스 WTS 허용 IP 관리에서 지금 주소를 추가하세요.

## 3. 매일 돌리기 — 화면에서 버튼으로

**`5_로봇화면.bat`** 을 실행하면 브라우저에 로봇 화면이 열려요 (이 PC 에서만 열리는 주소 `http://127.0.0.1:8777`).

| 버튼 | 하는 일 |
|---|---|
| **연습 시작** | 실제 주문 없이 실시간 가격으로 매매를 흉내 내요. 처음 2주는 이것만 |
| **실전 시작** | 진짜 주문. `config.json` 의 `"live": {"enabled": true}` 로 바꿔야 버튼이 켜져요 |
| **종료 · 보유 유지** | 새로 사지 않고 끝내요. 보유 종목은 토스 서버의 **시장가 손절 조건주문**이 지켜요 (PC를 꺼도, 다음 날 갭하락으로 시작해도 손절선 아래면 바로 팔림). 다음에 시작하면 이어받아요 |
| **종료 · 전부 팔기** | 보유 종목을 전부 시장가로 팔고 끝내요 |

화면에는 지금 단계(장 시작 대기 / 장중 매매 / 마감 정리), 보유 종목·수익률·손절선, 오늘 매도 내역과 손익, 기록이 2초마다 갱신돼요.
시작을 누른 시각부터 매매해요. 장 전이면 장 시작까지 기다렸다 시작하고, 15:15 마감 정리가 끝나면 스스로 멈춰요.
검은 창(콘솔)을 닫으면 로봇도 꺼져요 — 그래도 실전에서 걸어 둔 손절 조건주문은 토스 서버에 남아 있어요.

### 📱 휴대폰으로 조작하기

**방법 1. 텔레그램 (어디서나 · 추천)** — 사우디에서도, 밖에서도 인터넷만 되면 돼요.
1. 텔레그램 앱에서 **@BotFather** 검색 → `/newbot` → 봇 이름 두 번 입력 → **토큰**(예: `123456:ABC...`)을 받아요.
2. 방금 만든 봇과 대화를 열고 아무 말이나 보내요(예: `hi`).
3. PC 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id":숫자` 의 **숫자**를 찾아요.
4. 로봇 폴더의 `.env` 를 메모장으로 열어 `TG_TOKEN=토큰`, `TG_CHAT=숫자` 를 넣고 저장 → `5_로봇화면.bat` 다시 실행.
5. 봇 채팅방 아래에 버튼이 생겨요: **📊 상태 · ▶️ 연습 시작 · 🔴 실전 시작 · ⏹ 종료(보유 유지) · 💰 종료(전부 팔기)**.
   실전 시작·전부 팔기는 한 번 더 확인 메시지를 보내야 실행돼요. 매수·매도·하루 결과 알림도 같은 방으로 와요.
   내 채팅방(TG_CHAT)이 아닌 곳에서 보낸 명령은 무시해요.

**방법 2. 같은 와이파이에서 화면 그대로 열기**
1. `.env` 에 `APP_LAN=1`, `APP_PIN=` 뒤에 4~8자리 숫자를 넣고 저장 → `5_로봇화면.bat` 다시 실행.
2. 검은 창에 나오는 `📱 http://192.168.x.x:8777` 주소를 휴대폰 브라우저에서 열고 PIN 입력.
3. 윈도우 방화벽 창이 뜨면 **개인 네트워크만** 허용하세요. (카페·호텔 같은 공용 와이파이에서는 켜지 않는 게 좋아요)

PC 자체는 계속 켜져 있어야 해요 — 휴대폰은 리모컨이고, 실제 매매는 PC 의 로봇이 해요.

그 밖의 파일

| 파일 | 하는 일 |
|---|---|
| `2_연습모드.bat` / `3_실전모드.bat` | 화면 없이 바로 시작 (자동 실행 예약용) |
| `4_자동실행등록.bat` | 평일 국장 시작 10분 전에 자동으로 켜지게 예약 (켜진 채로 오후 미장까지 이어서 돌아요) |
| `6_실전주문시험.bat` | 장중에 1주로 실제 주문 흐름 시험. 지금 열린 시장을 알아서 골라요 (국장: 010140, 미장: 포드 F) |
| `긴급정지.bat` / `재개.bat` | 새로 사지 않고 보유분 즉시 매도 / 정지 풀기 |

### 주문 방식

| 언제 | 방식 | 이유 |
|---|---|---|
| 살 때 | **시장가** (기본) | 신호가 뜬 순간 바로 체결. 대신 매도·매수 호가 차이가 0.6% 넘게 벌어진 종목은 안 사요 (비싸게 사지 않게) |
| 손절 | **시장가 조건주문** (토스 서버 감시) | 손절선에 닿으면 바로 시장가로 팔려서, 급락·갭하락에도 안 팔리는 일이 없어요 |
| 절반 익절 · 추적 손절 매도 · 마감 정리 | **시장가** | 바로 체결 |

살 때 시장가 대신 지정가를 쓰려면 `config.json` 의 `"live": {"entry_order": "LIMIT"}` (매도 1호가 근처 지정가, 15초 안에 안 사지면 취소).

### 🇰🇷 국장 + 🇺🇸 미장 같이 돌리기

**시작 버튼 한 번이면 두 시장을 각각 따로 돌려요.** 화면에 국장 칸·미장 칸이 따로 나오고, 손익·매수 횟수·하루 손실 한도도 시장별로 따로 세요.

| 시장 | 사우디 시간 | 현지 시간 |
|---|---|---|
| 🇰🇷 국장 | 새벽 **03:00 ~ 09:30** | 09:00 ~ 15:30 |
| 🇺🇸 미장 | 오후 **16:30 ~ 23:00** (11월 2일부터 **17:30 ~ 24:00**) | 뉴욕 09:30 ~ 16:00 |

- 국장이 끝나면 국장 칸은 '다음 장 기다리는 중'이 되고, 오후에 미장이 열리면 미장 칸이 알아서 시작해요. 그 사이 PC는 켜 둔 채로(잠자기 OK) 두면 돼요.
- 미장 규칙은 같고 시간만 뉴욕 기준이에요: 15:00 이후 새로 안 사고, 15:45에 팔지·들고 갈지 정해요.
- **달러가 필요해요.** 토스 계좌에 달러가 없으면 미장 매수가 안 돼요. 미리 환전해 두거나, 토스 앱에서 **'원화로 바로 주문(자동 환전)'** 을 켜 두세요. 달러 주문 가능 금액이 예산보다 적으면 로봇이 기록에 알려 줘요.
- 한 시장만 돌리고 싶으면 `config.json` 의 `"markets": ["KR", "US"]` 에서 빼면 돼요. 예: 국장만 `["KR"]`.
- 미장 첫 주 한도는 1회 $70 · 한 번 손절 최대 $2 · 하루 손실 $7 이면 중단이라, **주가가 대략 $40 넘는 종목은 1주도 못 사서 건너뛰어요.** 1주일 뒤 한도를 올리면 살 수 있는 종목이 늘어요.

## 4. 로봇이 사고파는 규칙 (쉽게)

1. **후보 고르기 (장 시작 직후, 30분마다 갱신)**
   - 토스 실시간 거래대금 상위, 오늘 거래대금 상위, 오늘 상승률 상위
   - 깃허브 차트 분석의 '돌파'·'반등' 종목
   - 빼는 것: ETF·ETN·스팩·우선주, 투자경고·과열·VI(급등락 일시정지) 종목, 너무 싸거나 비싼 종목
2. **살 때 — 매수 방식 6가지** (여러 종목이 동시에 신호를 내면 가장 센 신호부터 사요. `config.json` → `strategy.setups` 에서 하나씩 끌 수 있어요)
   - ① **시초 돌파**: 아래 조건 (장 시작 15분 고점 돌파)
   - ② **VWAP 눌림 반등**: 아침에 강했던 종목이 오늘 평균 단가(VWAP)까지 쉬었다가 거래량 실어 다시 올라섬 (장 시작 30분 뒤부터)
   - ③ **오늘 고점 재돌파**: 고점 아래에서 10분 이상 좁게 쉬다가 오늘 최고가를 다시 거래량 실어 뚫음 (오후 추세, 45분 뒤부터)
   - ④ **지지선 반등**: 일봉 차트의 지지선(GitHub 차트 분석)에 닿았다가 양봉으로 돌아섬
   - ⑤ **레드→그린**: 어제보다 1% 넘게 낮게 시작했다가 어제 종가를 거래량 실어 처음 넘어섬
   - ⑦ **장초반 출발**: 데스크·차트가 전날 고른 종목이 장 시작 1~15분 안에 예상대로 힘 있게 출발하면(갭 +0.5~6%, 첫 1~2분 봉 고점 돌파, 시가·VWAP 위, 첫 봉 거래량이 평소 1분의 4배 이상) **15분 안 기다리고 바로** 사요. 데스크 1차 목표가 근처면 안 사요
   - ⑧ **실적 서프라이즈**: 실적이 예상보다 좋게 나온 종목(데스크가 발표 직후 판정)은 다음 장에 갭 +12% 까지 허용해 장초반 출발·눌림 반등으로 사요. 발표 **전**(오늘·내일 발표)과 실적 **실망** 종목은 새로 안 사요
   - 데스크 자료(1순위·픽·관심·장중 1순위·테마/이슈 종목·실적)는 10분마다 다시 읽고, 감시 종목은 최대 85개
   - ⑥ **데스크 가격 계획**: 주식비서 리포트의 1순위·픽·관심종목이 '진입 구간' 안에서 반등 (데스크 연결 시)
   - 공통: 오늘·내일 **실적 발표 종목은 새로 안 삼**(데스크 연결 시), 같은 종목은 하루 2번까지, 손절 뒤 30분은 다시 안 삼
   - 차트가 '관심'인 종목·데스크가 고른 종목은 점수를 더 줘서 먼저 사요
   **① 시초 돌파 조건 (아래를 모두 만족)**
   - 장 시작 후 15분 동안의 최고가를 뚫음 (시초 범위 돌파)
   - 오늘 평균 매수 단가(VWAP) 위
   - 직전 1분 거래량이 오늘 평소 1분 거래량의 **2배 이상**
   - 직전 1분봉이 양봉, 이미 +18% 넘게 오른 종목은 제외, 돌파 지점에서 1.5% 넘게 멀어졌으면 쫓지 않음
   - 매도·매수 호가 차이가 0.6% 넘게 벌어져 있으면 건너뜀
3. **산 다음 — 손절은 바로, 익절은 길게** (손절은 토스 서버에 조건주문으로 걸어 둠 → PC가 꺼져도 작동)
   - **첫 손절**: 돌파 지점·VWAP 바로 아래, 그리고 '이 종목이 평소 1분에 출렁이는 폭(ATR)의 3배' 중 더 넓은 쪽.
     너무 좁거나 넓지 않게 **−2.5% ~ −4.5%** 사이로 맞춰요. 잠깐 흔들림에 털리지 않게 하려는 거예요.
   - **본전 지키기**: 손절폭만큼(1R) 오르면 손절선을 산 가격 위로 올려요. 이때부터는 져도 본전.
   - **절반 익절**: 손절폭의 2배(2R, 보통 +5~9%) 오르면 절반만 팔아 이익을 확정해요.
   - **나머지는 추적 손절**: 고점이 높아질 때마다 손절선을 '고점에서 3%(또는 출렁임 폭의 4배) 아래'로 따라 올려요.
     계속 오르면 계속 들고 가고, 꺾여서 그 선을 깨면 팔아요. 고정 목표가로 일찍 팔지 않아요.
   - **최대 익절 +15%**: 하루에 15% 넘게 급등하면 그 자리에서 팔아요 (급등 후 급락 대비).
   - 손절은 **시장가 조건주문**이라 급락해도 바로 팔려요 (예비로, 손절선 아래에서 20초 넘게 안 팔리면 로봇이 직접 시장가 정리)
4. **시간 규칙**: 14:30 이후 새로 사지 않음. 15:15에 아래 기준으로 **팔지, 들고 갈지** 정해요.

### 추가 매수(불타기) — `config.json` → `pyramid`
- 이미 산 종목이 **1R 이상 올라 손절선이 본전 위로 올라간 뒤**(잃지 않는 상태), 같은 종목에 새 강한 신호(시초 돌파·오늘 고점 재돌파·VWAP 눌림 반등·장초반 출발·레드→그린, 확신도 B 이상)가 오면 **처음 수량의 절반까지** 더 사요.
- 추가 뒤 손절되면 잃는 돈이 '손절 1번 한도' 안에 들어오도록 수량을 줄여요. 종목당 최대 2번, 추가 사이 최소 15분. 손절 주문 수량도 같이 늘려요.

### 차트 좋은 종목은 스윙으로 — `config.json` → `swing`
- 일봉 차트 '관심'·돌파·추세, 데스크 스윙 후보(2~4주), 실적 서프라이즈 종목은 **스윙 후보**로 관리해요.
- 추적 손절 폭 3% → **6%**, 최대 익절 +15% → **+40%**, 들고 가기 기준 +3% → **+0.5%**, 최대 20일·3종목.
- 밤사이 손절선은 '지금가 −7% 또는 일봉 지지선 바로 아래'(넓게), 수익 2% 넘으면 본전은 지켜요. 절반 익절(2R)은 그대로 해서 '익절하면서 나머지는 길게' 가져가요.

### 이익 난 종목은 다음 날까지 들고 가기 (`config.json` → `carry`)

국장 15:15 · 미장 15:45(뉴욕 시간)에 보유 중인 종목마다:

| 조건 (모두 만족하면 들고 감) | 기본값 |
|---|---|
| 지금 수익이 기준 이상 | +3% 이상 (`min_profit_pct`) |
| 오늘 평균 매수 단가(VWAP) 위에서 끝남 (힘이 남아 있음) | 켜짐 (`require_above_vwap`) |
| 보유 기간이 최대 일수 안 | 10일 (`max_days`) |
| 들고 가는 종목 수 | 최대 2개 (`max_positions`) |

- 하나라도 안 맞으면 그날 팔아요. 이익이 적거나 힘이 빠진 종목은 들고 가지 않아요.
- 들고 갈 때 **밤사이 손절선**은 아래 셋 중 가장 높은 값으로 올려요.
  - 지금 추적 손절선
  - 산 가격 +1% (`lock_profit_pct`, 최소 이만큼 이익은 지킴)
  - 지금 가격 −5% (`carry_stop_pct`)
- 토스 서버의 손절 조건주문 만료일을 며칠 뒤로 늘리고, 최대 익절가는 +30%로 올려요.
- 다음 날 로봇이 켜지면 이어받아요.
  - 실전 모드는 계좌에 정말 있는지, 손절 조건주문이 살아 있는지 확인하고, 없으면 다시 걸어요.
  - 이어받은 뒤에도 추적 손절을 계속 따라 올려요.
  - 그날 15:15에 다시 기준을 보고 더 들고 갈지 정해요.
- 이렇게 **오르는 동안은 계속 들고 가고, 꺾여서 손절선을 깨거나 힘이 빠지면** 팔아요.

밤사이 손절은 **시장가 조건주문**이라, 다음 날 손절선보다 아래에서 시작(갭하락)해도 장이 열리자마자 토스 서버가 바로 팔아요. PC가 꺼져 있어도 작동해요. 단, 시장가라 손절선보다 낮은 값에 팔릴 수 있어요(갭만큼). 들고 가기를 끄려면 `"carry": {"enabled": false}`.

## 5. 오늘 투자금과 안전장치 (`config.json` → `risk`)

**'오늘 투자금'만 정하면 로봇이 그 안에서 알아서 나눠 사요.** 계좌에 돈이 더 있어도 이 금액을 넘지 않아요.
- 정하는 곳: 로봇 화면의 국장·미장 칸 **'오늘 투자금' → 정하기**, 또는 텔레그램에 `투자금 국장 50만` / `투자금 미장 400`
- 실행 중에 바꿔도 바로 반영돼요 (이미 산 종목은 그대로).

| 설정 | 기본값 | 뜻 (투자금 50만 원일 때) |
|---|---|---|
| `daily_capital` | 국장 500,000원 · 미장 $350 | 오늘 굴릴 돈 |
| `max_position_pct` | 40% | 한 종목 최대 약 20만 원. 신호가 셀수록(거래량 급증) 0.85~1.25배로 더 넣어요 |
| `risk_per_trade_pct` | 1% | 손절되면 잃는 돈이 약 5,000원 이하가 되게 수량 조절. 손절폭이 넓은 종목은 덜 사요 |
| `min_position_pct` | 8% | 4만 원도 못 살 만큼 남았으면 새로 안 사요 |
| `daily_loss_pct` | 3% | 오늘 손실이 15,000원이 되면 그날은 중단 |
| `max_positions` | 4 | 동시에 들고 있는 종목 수 (들고 가는 종목 포함) |
| `max_trades_per_day` | 10 | 하루 최대 매수 횟수 |
| `max_losses_in_row` | 3 | 연속 손절 3번이면 그날은 중단 |

- **확신도에 따라 비중을 바꿔요.** 신호 점수(매수 방식·거래량·차트 '관심'·데스크 1순위/픽·실적 서프라이즈)로 등급을 매겨요.
  A+ 1.7배 · A 1.35배 · B 1.0배 · C 0.75배 (한 종목 최대 투자금의 65%, 손절 1번 최대 1.8%까지). 하루 손실 한도(3%)는 그대로예요. `risk.conviction` 에서 바꿀 수 있어요.
- 팔면 그 돈이 다시 '남은 돈'이 되어 다른 종목에 써요. **이익은 다시 넣지 않고**(오늘 정한 금액 유지), 손실이 나면 그만큼 남은 돈이 줄어요.
- 계좌의 매수 가능 금액이 투자금보다 적으면 그 안에서만 사요.

그 밖에
- 같은 종목은 하루 1번만, 손절한 종목은 30분 동안 다시 안 삼
- 조건주문(익절·손절)을 못 걸면 **즉시 팔아요** (손절 없는 보유 금지)
- 실전 모드는 `live.enabled` 를 직접 true 로 바꾸기 전에는 절대 주문하지 않아요
- 프로그램을 껐다 켜도 보유분을 이어받아요 (시장별로 `logs/live/KR`, `logs/live/US` 에 저장)

익절·손절 숫자는 `config.json` 의 `strategy` → `stop`(손절), `take_profit`(본전·절반 익절·추적 손절)에서 바꿔요.
숫자를 바꾸려면 `config.json` 을 메모장으로 열어 고치고 저장하면 다음 실행부터 반영돼요.

## 6. 알아둘 점

- **허용 IP**: 집·숙소 인터넷 주소는 가끔 바뀌어요. 그러면 `403` 이 나고 로봇이 시작하지 못해요. 토스 WTS 허용 IP 관리에서 새 주소를 추가하세요.
- **"투자자지시 거래소 통합(SOR)이 아닙니다"** 오류가 나면: 토스 앱 설정에서 주문 거래소를 '통합(SOR)'으로 바꾸세요.
- **PC가 장중에 꺼지면**: 시장가 손절 조건주문은 토스 서버에 살아 있어서 손절선 아래로 가면 팔려요. 다만 추적 손절선 올리기·15:15 정리는 로봇이 켜져 있어야 해요. 조건주문 만료일은 그날(들고 가는 종목은 며칠 뒤)이에요.
- **연습 모드 결과는 실제보다 좋게 나올 수 있어요** (호가 1칸 미끄러짐만 반영). 실전은 체결이 더 불리할 수 있어요.
- 텔레그램 알림을 받으려면 `.env` 에 `TG_TOKEN`, `TG_CHAT` 을 넣으세요 (매수·매도·하루 결과 알림).
- 이 폴더를 깃허브에 올린다면 반드시 **비공개(Private) 저장소**에, `.env` 는 올라가지 않게 (`.gitignore` 에 들어 있어요).
