# 클라우드 서버(Vultr 서울 · 월 약 $5~6)에 로봇 옮기기

서버 = 인터넷 회사에 있는 **24시간 안 꺼지는 내 컴퓨터**. 회사·숙소 PC 를 켜 둘 필요가 없어요.
조작·알림은 **텔레그램**으로 해요 → `.env` 에 TG_TOKEN, TG_CHAT 이 꼭 있어야 해요.
**키·비밀번호·IP 는 채팅·캡처에 올리지 말고 직접 붙여 넣기만** 하세요.

## 1. Vultr 가입 (10분)
1. https://www.vultr.com → **Sign up** → 이메일·비밀번호 → 메일함에서 인증 링크 클릭
2. **Billing** → 카드 등록 → **최소 금액($10)만** 충전 (선불은 환불 안 됨)
3. 오른쪽 위 계정 → **Account → Two Factor Authentication** 켜기 (휴대폰 OTP 앱, 예: Google Authenticator)
   - 카드 사진·신분증 확인을 요청받으면 안내대로 하면 돼요 (가끔 있어요)

## 2. 서버 만들기 (5분)
1. **Deploy +** (파란 버튼) → **Deploy New Server**
2. 고르기
   - Type: **Shared CPU** (Cloud Compute)
   - Location: **Seoul** (토스 서버와 가까워야 주문이 빨라요)
   - Image(OS): **Ubuntu 24.04 LTS x64**
   - Plan: 가장 싼 **1 vCPU · 1 GB · IPv4 포함** ($5 또는 $6/mo 로 표시된 것)
   - **Auto Backups: 끄기(Disable)** → 경고가 나오면 동의 체크
   - 나머지(IPv6, DDoS Protection 등)는 **끈 그대로**
   - Hostname: `tossbot`
3. **Deploy Now** → 2~3분 뒤 상태가 **Running**
4. 서버 이름을 눌러 들어가면 **IP Address** 와 **Password**(눈 아이콘·복사 버튼)가 보여요. 메모장에 적어 두세요.

## 3. 토스에 서버 IP 등록
토스증권 WTS → Open API 설정 → **허용 IP 관리** → 2-4 의 IP Address 추가.
(지금 PC 주소는 그대로 둬도 돼요)

## 4. 로봇 파일 올리기 (윈도우 PowerShell)
1. `tossbot.zip` 을 **다운로드 폴더**에 두고 이름이 정확히 `tossbot.zip` 인지 확인 (`tossbot (1).zip` 이면 이름 바꾸기)
2. 시작 버튼 → `powershell` 검색 → **Windows PowerShell** 열기
3. 아래를 붙여 넣되 `서버IP` 를 실제 IP 로 바꿔서 Enter
   ```
   scp "$env:USERPROFILE\Downloads\tossbot.zip" root@서버IP:~
   ```
   - 처음엔 `Are you sure you want to continue connecting` → `yes` 입력 후 Enter
   - `password:` 가 나오면 2-4 의 Password 를 **마우스 오른쪽 클릭으로 붙여 넣고** Enter
     (입력해도 화면에 아무것도 안 보이는 게 정상이에요)
   - `100%` 가 보이면 올라간 거예요

> 회사 네트워크가 막아서 `Connection timed out` 이 나오면: 휴대폰 핫스팟에 연결해서 다시 하거나, 개인 노트북에서 하세요.

## 5. 서버에 접속해서 설치 (5분)
1. 같은 PowerShell 에
   ```
   ssh root@서버IP
   ```
   → 비밀번호 붙여 넣고 Enter → `root@tossbot:~#` 가 보이면 서버 안이에요
2. 아래 한 줄 붙여 넣고 Enter
   ```
   apt-get update -qq && apt-get install -y unzip && unzip -o tossbot.zip && bash tossbot/server/setup.sh
   ```
3. "준비되면 Enter" 에서 Enter → 메모장(nano)이 열리면 `=` 뒤에 4개 값 붙여 넣기 (마우스 오른쪽 클릭)
   - `TOSS_CLIENT_ID=` `TOSS_CLIENT_SECRET=` `TG_TOKEN=` `TG_CHAT=`
   - 저장 **Ctrl+O → Enter**, 닫기 **Ctrl+X**
4. "3/4 연결 확인" 에 토큰·계좌·현재가가 나오면 성공 (`403` 이면 3번 허용 IP 확인 → `tb 키` 로 다시 저장)
5. **✅ 설치 끝** + 텔레그램에 "🤖 로봇 프로그램이 켜졌어요" 메시지가 오면 완료. PowerShell 창은 닫아도 돼요 (서버는 계속 돌아요).

## 6. 시작
1. **회사 PC 에서 돌던 로봇은 꺼요** (5번 화면 → 종료·보유 유지 → 창 닫기). 같은 계좌를 두 로봇이 굴리면 안 돼요.
2. 텔레그램 → **📊 상태** → **🔴 실전 시작** → `실전 시작 확인`
3. 투자금: `투자금 국장 50만`, `투자금 미장 350` (💵 투자금 버튼으로 지금 값 보기)

서버가 업데이트로 재부팅돼도 **켜져 있던 상태 그대로 다시 시작**하고 텔레그램으로 알려 줘요.

## 서버 명령 (PowerShell 에서 `ssh root@서버IP` 로 들어간 뒤)
| 명령 | 하는 일 |
|---|---|
| `tb 기록` | 최근 기록 (`tb 실시간` 은 계속 보기, 나가기 Ctrl+C) |
| `tb 확인` | 토스 연결 확인 |
| `tb 시험` | 장중 1주 실전 주문 시험 |
| `tb 키` | `.env` 고치기(키 재발급 시) → 저장하면 자동 재시작 |
| `tb 재시작` / `tb 끄기` | 로봇 프로그램 다시 켜기 / 끄기 |
| `tb 업데이트` | 새 zip 을 4번처럼 올린 뒤 실행 → 새 버전으로 교체 (`.env`·투자금 그대로) |
| `exit` | 서버에서 나오기 |

## 비용·보안
- 24시간 돌려도 **월 플랜 가격($5~6)이 최대**. 매매 횟수와 무관해요.
- 그만 쓸 때는 서버를 **Destroy(삭제)** 해야 요금이 멈춰요 (끄기만으로는 계속 청구).
- 설치 때 자동으로: 방화벽(SSH 만 허용), 비밀번호 무작위 대입 차단(fail2ban), 보안 업데이트 자동 설치.
- 로봇 화면(8777)은 서버 밖으로 열리지 않아요. 조작은 텔레그램으로만.
